# Event Horizon 🚀

A modern, animated event countdown application built with React. Track multiple events with style!

## Features ✅

- [x] **Multiple Countdowns**: Create and manage unlimited event countdowns
- [x] **Persistent Storage**: Events are saved automatically so you don't lose them
- [x] **Dashboard View**: View all your upcoming events in a responsive grid
- [x] **Smooth Animations**: Engaging UI interactions powered by Framer Motion
- [x] **Event Management**: Easily add and delete events

## How to Run Locally 💻

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd event-countdown
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open in Browser**
   Open the URL shown in the terminal (usually `http://localhost:5173`)
